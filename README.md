# Amharic designs

Sample Amharic web work, plus the [font.et](https://font.et/) free Ethiopic catalog.

## Sample

Open [`index.html`](index.html) for **ሸገር ቤት**, a compact Amharic landing page set in [Bela Hidase](font-et/bela-hidase/).

## Fonts

`font-et/` contains 109 families (171 TTF/OTF files) downloaded from font.et on 2026-11-01. Each family has its own folder and a `LICENSE.txt` copied from the catalog.

Many families are SIL Open Font License or GPL. About half have no license listed. Review the file in the family folder before commercial use. A few unlabeled names may still be proprietary vendor fonts.

See [`font-et/README.txt`](font-et/README.txt) for the original download notes.
